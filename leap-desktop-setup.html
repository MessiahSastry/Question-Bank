DESKTOP ONLY · Bookmarklet 1.0 · Based on mobile helper 1.2.8

St. Patrick's — Desktop LEAP

Use Chrome or Edge on a laptop or desktop. No extension is required for this separate option. Your existing mobile Tampermonkey setup is unchanged.

1. Install the bookmark

Show the bookmarks bar using Ctrl+Shift+B. Drag the green bookmark below to the bookmarks bar. If dragging is blocked, copy the bookmark URL and create or edit a bookmark named LEAP Desktop, pasting the complete URL into its URL field.

LEAP Desktop

2. Prepare marks in the school app

  1. Open the school marks app and select class, section and exam.
  2. Click the LEAP Desktop bookmark (not the normal Send to LEAP button).
  3. Complete any existing SA-1 prompts. Click Copy marks data and open LEAP using the link in the panel.

3. Fill the LEAP portal

  1. Log in and open the marks-entry page.
  2. Click the same bookmark. Click Read copied marks or paste the data manually, then load it.
  3. Click Fill Details, select the student and get details, click Fill Marks, verify and save manually.
  4. If the portal reloads, click the bookmark again and reload the same copied data. Recopy from the school app if necessary.
Important: Use only one method at a time. The desktop helper does not store student data in LEAP session/local storage or automatically save marks. Clipboard data contains student details: use an authorised computer, avoid shared clipboard syncing, and overwrite the clipboard after finishing. Copied data expires after four hours. Existing supported exams and section mapping remain unchanged (Classes 8–10 standalone A → D; A Section → A). Class 10 SA-1 remains unsupported pending format verification.

Browser security policies may block bookmarklet execution or clipboard access. Manual paste is provided for clipboard restrictions; portal-specific browser testing is required.
